# BALTHVS — Page Titles & Meta Descriptions

## Where to put these in WordPress (SeoPress installed)

- **Page title (`<title>` tag):** open the page in WordPress → scroll to the **SeoPress metabox** (below the content, or the SeoPress panel in the sidebar) → **Title settings** tab → paste the title into the **Title** field. SeoPress uses it verbatim and no longer lets the theme append ` – BALTHVS`, so the title below must already contain the full string you want (brand included where wanted).
- **Meta description:** same SeoPress metabox → **Title settings** tab → **Meta description** field → paste the meta below. (Native WordPress has no such field; SeoPress provides it.)
- Do not paste the title/meta into the Custom-HTML block body — Google reads the `<head>`, which SeoPress now controls.
- **JSON-LD (structured data):** already inside each page's Custom-HTML block; nothing to place by hand. It works from the body; no `<head>` access required.
